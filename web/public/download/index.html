Testnet / local wallet helper only. Not a hosted web wallet. Not a token sale. Write RPC stays on this machine.

What this is

  • A desktop helper packaged from web/addition_wallet_gui.py and web/addition_wallet.py
  • Talks only to 127.0.0.1:8545 (or ::1 / localhost)
  • Refuses any other RPC host
  • Keys stay on disk. The helper never prints a private key
  • Needs a local additiond --network testnet

additionblockchain.com has no write RPC. The public /wallet/ page stays RPC offline on this host.

Linux (testnet / local)

addition-wallet-testnet — GUI + --cli

addition-wallet-cli-testnet — caller-disk CLI

chmod +x addition-wallet-testnet
# terminal 1
additiond --network testnet
# terminal 2
./addition-wallet-testnet --cli getinfo
# optional GUI (needs a display)
./addition-wallet-testnet

If the file is not on this host yet, build it from the repo: ./scripts/build_wallet.sh

Windows (testnet / local)

Build addition-wallet-testnet.exe on a Windows machine:

powershell -File scripts\build_wallet.ps1

Then run addition-wallet-testnet.exe --cli getinfo against a local additiond --network testnet on 127.0.0.1:8545.
