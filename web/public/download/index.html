Mainnet / local wallet helper for ADDITION_MAINNET_V1. Write RPC stays on this machine (127.0.0.1:8546). Prefer the in-browser Wallet PWA when ADDITION_NETWORK=mainnet python3 web/serve.py sits next to your node (spend path: /local-rpc).

Not a hosted custodial wallet. Keys stay on disk. The helper refuses any RPC host other than loopback. Public read 34.27.30.115:38546 has no wallet_send.

What this is

  • A desktop helper packaged from web/addition_wallet_gui.py and web/addition_wallet.py
  • Talks only to 127.0.0.1:8546 by default (or ::1 / localhost)
  • Refuses any other RPC host — including public 38545 / 38546 / :80
  • Never prints a private key
  • Needs a local additiond --mainnet with write RPC on loopback

additionblockchain.com has no write RPC. The public /wallet/ page stays fail-closed there and explains how to connect a home node. PWA spend is /local-rpc → loopback only.

Linux (mainnet / local)

These are Linux commands. Do not paste them into PowerShell.

addition-wallet-mainnet — GUI + --cli

addition-wallet-cli-mainnet — caller-disk CLI

chmod +x addition-wallet-mainnet
# terminal 1
additiond --mainnet --data-dir $HOME/addition-mainnet --local-rpc-port 8546
# terminal 2
./addition-wallet-mainnet --cli getinfo
# optional GUI (needs a display)
./addition-wallet-mainnet

Install the website as an app

On iPhone: Safari → Share → Add to Home Screen. On Android: Chrome → Install app / Add to Home screen. That installs this PWA; spending still needs your local node via /local-rpc.
