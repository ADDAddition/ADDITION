Testnet / local wallet helper only. Not a hosted web wallet. Write RPC stays on this machine.

What this is

  • A desktop helper packaged from web/addition_wallet_gui.py and web/addition_wallet.py
  • Talks only to a local additiond on 127.0.0.1:8545 (or ::1 / localhost)
  • Refuses any other RPC host
  • Keys stay on disk. The helper never prints a private key
  • Needs a local additiond --network testnet

additionblockchain.com has no write RPC. The public /wallet/ page stays RPC offline on this host.

Windows (testnet / local)

PowerShell for a cashier PC (caisse1b). Do not paste Linux chmod, sudo, or apt. Cashiers download; they do not compile.

addition-wallet-testnet.exe — GUI + --cli

addition-wallet-cli-testnet.exe — caller-disk CLI

Windows binaries land in web/public/download/. This Linux tree cannot build those .exe files. Drop them in that folder so the links serve files.

# PowerShell — talks to a local additiond on 127.0.0.1:8545 only
# The public host has no write RPC. The helper refuses non-loopback RPC.

# terminal 1
additiond --network testnet --data-dir $HOME\addition-testnet --local-rpc-port 8545
# terminal 2
.\addition-wallet-testnet.exe --cli getinfo
# optional GUI
.\addition-wallet-testnet.exe

Linux (testnet / local)

These are Linux commands. Do not paste them into PowerShell.

addition-wallet-testnet — GUI + --cli

addition-wallet-cli-testnet — caller-disk CLI

chmod +x addition-wallet-testnet
# terminal 1
additiond --network testnet --data-dir $HOME/addition-testnet
# terminal 2
./addition-wallet-testnet --cli getinfo
# optional GUI (needs a display)
./addition-wallet-testnet
