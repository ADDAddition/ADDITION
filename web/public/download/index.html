Desktop helper

Download

Testnet / local wallet helper. Write RPC stays on this machine. Prefer the in-browser Wallet PWA when python3 web/serve.py sits next to your node.

Not a hosted custodial wallet. Keys stay on disk. The helper refuses any RPC host other than loopback.

What this is

  • A desktop helper packaged from web/addition_wallet_gui.py and web/addition_wallet.py
  • Talks only to 127.0.0.1:8545 (or ::1 / localhost)
  • Refuses any other RPC host — including public 38545 / 38546 / :80
  • Never prints a private key
  • Needs a local additiond --network testnet

additionblockchain.com has no write RPC. The public /wallet/ page stays fail-closed there and explains how to connect a home node.

Cashiers / Windows

Download the live wallet files on this page. Do not compile. There is no Windows compile path here. This host does not publish a .exe.

addition-wallet-cli-testnet — caller-disk CLI

Linux (testnet / local)

These are Linux commands. Do not paste them into PowerShell.

addition-wallet-testnet — GUI + --cli

addition-wallet-cli-testnet — caller-disk CLI

chmod +x addition-wallet-testnet
# terminal 1
additiond --network testnet --data-dir $HOME/addition-testnet
# terminal 2
./addition-wallet-testnet --cli getinfo
# optional GUI (needs a display)
./addition-wallet-testnet

Install the website as an app

On iPhone: Safari → Share → Add to Home Screen. On Android: Chrome → Install app / Add to Home screen. That installs this PWA; spending still needs your local node.
