MAINNET Live privacy

Opening privacy

On ADDITION_MAINNET_V1, the live privacy claim is opening_not_zk: SHA3-512 commitment + nullifier opening. The node sees the trapdoor. This is not zero-knowledge and not Monero/Zcash privacy.

What is live

  • privacy_claim=opening_not_zk on live getinfo / privacy_status
  • Opening RPCs on a home node (loopback write): privacy_note_prepare, privacy_mint_open, privacy_spend_open
  • Requires ADDITION_PRIVACY_MASTER_KEY (≥32 chars) on the daemon

Public Pages do not host mint/spend forms — those need your node’s loopback write RPC via local tools next to additiond. Confirm the claim on network status (live strip includes privacy_claim).
