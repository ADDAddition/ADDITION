This page documents the read-only public port. It is not a JSON-RPC marketplace and not a live mainnet endpoint advertisement.

Checking RPC…

Example: getinfo


    

    

      
Enable the port

      
./build/additiond --network testnet --public-rpc
# or
ADDITION_ENABLE_PUBLIC_RPC=1 ./build/additiond --network testnet

      
Default bind: 0.0.0.0:38545. Override with --public-rpc-port, --public-rpc-bind, ADDITION_PUBLIC_RPC_PORT, ADDITION_PUBLIC_RPC_BIND.

    

    

      
Talk to it

      
One command line in, one response line out (same as local RPC):

      
printf 'getinfo\n' | nc HOST 38545
curl 'http://HOST:38545/rpc?cmd=getinfo'
curl 'http://HOST:38545/rpc?cmd=getblock%200'

      
Allowlist:

      
    
        
  • getinfo
    • 
        
  • monetary_info
    • 
        
  • crypto_selftest
    • 
        
  • tx_status <tx_hash>
    • 
        
  • peers
    • 
        
  • getblock <height_or_hash>
    • 
        
  • getblockhash <height>
    • 
      

      
Everything else, including mine, sendtx*, createwallet, wallet_*, and identity rotation, returns error: command disabled on public RPC.

      
Wallet create/send lives on localhost: /wallet/ or python3 web/addition_wallet_gui.py.

    

    

      
What stays private

      
    
        
  • Trusted RPC: 127.0.0.1:8545 (optional ADDITION_RPC_TOKEN)
    • 
        
  • LAN RPC: off unless ADDITION_ENABLE_LAN_RPC=1 and ADDITION_LAN_RPC_TOKEN
    • 
        
  • P2P: off unless ADDITION_ENABLE_P2P_RPC=1
    • 
      

      
Two local processes: two-node runbook. Website PUBLIC_RPC_HTTP stays empty until an operator sets the real HTTP URL. Do not commit trycloudflare URLs.

      
Do not open unauthenticated write RPC to the world. Full command list: Commands.

      
Speed and fees: show only fields the node returned (last_tps, dynamic_min_fee, …). Spec min_fee=1. This page does not invent USD costs.
