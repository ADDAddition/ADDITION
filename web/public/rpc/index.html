    Example: getinfo
    
      
    
    
    
    
    
      
    Enable the port
    
      
    ./build/additiond --network testnet --public-rpc
# or
ADDITION_ENABLE_PUBLIC_RPC=1 ./build/additiond --network testnet
    
      
    Default bind: 0.0.0.0:38545. Override with --public-rpc-port, --public-rpc-bind, ADDITION_PUBLIC_RPC_PORT, ADDITION_PUBLIC_RPC_BIND.
    
    
    
    
    
      
    Talk to it
    
      
    One command line in, one response line out (same as local RPC):
    
      
    curl 'https://rpc.additionblockchain.com/rpc?cmd=getinfo'
curl 'http://34.27.30.115/rpc?cmd=getinfo'
curl 'http://34.27.30.115:38545/rpc?cmd=getinfo'
curl 'http://34.27.30.115:38545/jsonrpc?method=getinfo'
curl 'http://34.27.30.115:38545/jsonrpc?method=getblockraw¶ms=0'
printf 'getinfo\n' | nc 34.27.30.115 38545
    
      
    Those curls succeed only when the operator seed answers. If they timeout, run a local --public-rpc node.
    
      
    :80 (nginx) works when 38545 is filtered. Path is /rpc?cmd=getinfo or /jsonrpc?method=getinfo, not /getinfo.

    Public-read JSON API
    
      
    Same allowlist. No write commands. Not Ethereum JSON-RPC. Not a third-party dRPC vendor.

    GET  http://HOST:38545/jsonrpc?method=getinfo
