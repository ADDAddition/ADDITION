Public RPC

Anyone can call a node's public port for read-only commands. Wallet, mining and send commands only answer on loopback (127.0.0.1) on your own machine.

Allowed on the public port: getinfo, monetary_info, crypto_selftest, tx_status, peers, getblock, getblockhash, getblockraw. Everything else is refused.

    Example: getinfo
    
      
    
    
    
    
    
      
    Enable it on your node
    
      
    ./build/additiond --public-rpc --public-rpc-port 38545   # testnet default
# or: ADDITION_ENABLE_PUBLIC_RPC=1 ./build/additiond
    
      
    Default ports: testnet 38545, mainnet profile 38546. Trusted write RPC stays on 127.0.0.1 (8545 testnet / 8546 mainnet), optionally protected by ADDITION_RPC_TOKEN.
    
      
    curl -s 'http://127.0.0.1:38545/rpc?cmd=getinfo'
