Research goals (design targets, not a live network)

      
    
        
  1. Quantum — ML-DSA-87 (FIPS 204) signatures; pq_mode=strict when the node answers getinfo.
    2. 
        
  2. Privacy — native ZK path (pq_mldsa87); notes do not persist plaintext owner/amount.
    3. 
        
  3. Speed — local testnet RPC. This page shows only fields a running node returned.
    4. 
        
  4. Cost of transaction — spec min_fee=1. No invented USD fees or gas market.
    5. 
        
  5. Compatibility — in-process bridge_* commands and the EVM bootstrap. Not a full EVM, not live Uniswap, not connected to every chain today.
    6. 
      

      
Kernel constants such as max_supply = 50,000,000 and SHA3-512 hashing are design parameters. They are not public hashrate, listed markets, or a running mainnet.

cmake --build build --target additiond
./build/additiond --network testnet --public-rpc
