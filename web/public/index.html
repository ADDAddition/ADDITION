ADDITION

Research prototype / honest testnet. Not a live mainnet.

Home Explorer Status Contracts Swap EVM bridge
This repository does not run a public mainnet, token sale, or CoinMarketCap listing. If the read RPC is down, pages show RPC offline and stay empty. They never invent blocks, hashrate, node counts, or supply.

Public read RPC

Trusted local RPC stays on 127.0.0.1:8545 (writes, wallets, mine). The public port is read-only.

ADDITION_ENABLE_PUBLIC_RPC=1 ./build/additiond --network testnet
# or
./build/additiond --network testnet --public-rpc

printf 'getinfo\n' | nc HOST 38545
curl 'http://HOST:38545/rpc?cmd=getinfo'

Allowlist: getinfo, monetary_info, crypto_selftest, tx_status, peers, getblock, getblockhash.

LAN/P2P stay off unless you set ADDITION_ENABLE_LAN_RPC=1 (token required) or ADDITION_ENABLE_P2P_RPC=1. Do not open unauthenticated write RPC to the world.

Site

Serve these pages locally (binds loopback by default):

python3 web/serve.py

Then open http://127.0.0.1:8080/explorer. Optional ?rpc=http://HOST:38545/rpc points the pages at a public read HTTP endpoint.
