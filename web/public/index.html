A Layer 1 built for the post-quantum era

ADDITION is an open-source C++20 blockchain. Every spend is signed with ML-DSA-87 (NIST FIPS 204), blocks are hashed with SHA3-512, and supply is capped at 50 million ADD.

What is in the code

The features below are implemented in the repository and covered by tests on local testnets. None of them runs on a public mainnet yet.

Cryptography

Post-quantum signatures

ML-DSA-87 through liboqs, with an on-chain public-key registry. No classical signature fallback.

Consensus

Memory-hard PoW, then staking

PoW from genesis. Ticket staking takes 30% of rewards from height 14,772,727, with slashing for double votes.

Privacy

STARK shielded pool

Shielded notes with STARK proofs, nullifiers and encrypted memos.

Layer 2

HTLC payment channels

Off-chain channels with multi-hop HTLC routing and timelocks.

Messaging

AMLS1 encrypted messages

Client-held ML-DSA-87 / ML-KEM-1024 keys. Nodes relay and store ciphertext only.

Network

Tor by default

Onion-only peering with a post-quantum handshake. No DNS seeds.

Protocol parameters

Mainnet consensus constants as written in the source.

SignaturesML-DSA-87 (NIST FIPS 204) only, via liboqs. No ECDSA, no Falcon. pq_mode=strict.
HashingSHA3-512
Supply50,000,000 ADD hard cap, genesis mints 0, no tail emission
Block time20 s target, LWMA retarget (180-block window)
Block reward4 ADD (heights 1 to 5,681,818), 2 ADD (to 11,363,637), then 1 ADD until the cap at height 27,272,727 (about 17.3 years). After that, fees only.
Proof of workMemory-hard PoW over SHA3-512
StakingTicket staking activates at height 14,772,727 (when 37.5M ADD have been emitted, about 9.4 years). From then on 30% of each reward goes to voting stakers. Equivocation is slashed.
Private paymentsShielded pool with STARK proofs, nullifiers and encrypted memos
Layer 2Payment channels with HTLC multi-hop routing and timelocks
MessagingAMLS1 end-to-end messaging: ML-DSA-87 identities, ML-KEM-1024 handshake; the node only relays
NetworkP2P over Tor v3 onion services with a post-quantum handshake. Mainnet seeds are onion-only, no DNS seeds.

Values come from include/addition/config.hpp in the source code. Throughput is not advertised.
