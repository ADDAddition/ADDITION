What this is

      
    
        
  • Fees — min_fee=0. Empty mempool: recommended_min_fee=0. Swap fee_bps=0 is allowed. Congestion can raise the native floor. Not a Solana/XRP throughput claim.
    • 
        
  • PQ — spend signatures are ML-DSA-87 (pq_mode=strict). That is the quantum-resistant property that exists. Not FIPS 140-3.
    • 
        
  • Privacy — SHA3-512 opening. The node sees the trapdoor. claim=opening_not_zk. Not Monero, not Zcash, not a circuit.
    • 
        
  • Speed — last_tps is measured. research_goal_tps is labeled not a measurement. PoW is SHA3-512 (testnet) or memory_hard (mainnet profile).
    • 
        
  • Contracts — in-process KV contract_deploy / contract_call. Not a scalable VM.
    • 
        
  • Other chains — EVM helper is a send-disabled bootstrap. Not IBC, not a bridge, not MetaMask public RPC.
    • 
      

    

    

      
What this is not

      
    
        
  • Not a hosted web wallet, Uniswap, or public token sale
    • 
        
  • Not Groth16 / Bulletproofs / ZK-Shield
    • 
        
  • Token and swap writes are unsigned TEXT RPC on loopback. Anyone who can reach 8545 can name an owner
    • 
        
  • EVM helper is a bootstrap. It is not a full EVM and cannot send
