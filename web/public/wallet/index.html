This wallet talks only to a node you run, through /local-rpc to 127.0.0.1 (8545 testnet / 8546 mainnet profile). Keys stay in that node's data/wallets/. The public RPC is read-only and never receives wallet commands.

RPC offline

No local node answered on /local-rpc. The hosted site cannot reach your machine: run the node and serve this site locally.

  1. Or run additiond locally Start additiond (testnet) with write RPC on 127.0.0.1:8545 only. Never bind write RPC on 0.0.0.0.
  2. Serve this site next to the node From the repo: python3 web/serve.py, then open the printed local address, so /local-rpc reaches your node.
