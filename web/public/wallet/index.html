Connect your home node

Spending needs a node on this device (or LAN loopback). Public sites never hold your keys.

  1. Run additiond locally Start a testnet node with write RPC on 127.0.0.1:8545 only — never bind write on 0.0.0.0.
  2. Serve this site next to the node From the repo: python3 web/serve.py so /local-rpc can reach loopback.
  3. Refresh this page When the node answers, Create wallet or Open existing appears here. Public :80 / 38545 stay read-only.
