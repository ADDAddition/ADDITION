createwallet, wallet_send, and mine go to /local-rpc → 127.0.0.1:8545. Run python3 web/serve.py next to a local node. The public read port (:38545) does not accept those commands. Keys stay in data/wallets/<name>.wal (ML-DSA-87).

Checking local RPC…

What this is

  • UTXO receive/send, createwallet (ML-DSA-87), getbalance / wallet_balance
  • Default send: wallet_send (node signs from the local file; no raw privkey on the wire)
  • Explicit send: tx_build + wallet_sign + sendtx_signed
  • Fees: spec min_fee=1, plus the node’s fee_info floor. Cap: 50,000,000
  • Desktop helper: python3 web/addition_wallet_gui.py (same local RPC)

“Like Bitcoin” here means the user model. This tree does not implement BIP-32/39/44 or Bitcoin P2P/script.
