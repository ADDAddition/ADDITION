Run additiond

Build from this tree, then start the daemon on testnet.

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target additiond
./build/additiond --network testnet

Needs liboqs + OpenSSL. Details: Build and run.

Ports

  • Write RPC: 127.0.0.1:8545 — mine, createwallet, wallet_*
  • Public read: :38545 — getinfo, getblock, monetary_info, peers
./build/additiond --network testnet --public-rpc
printf 'getinfo\n' | nc 127.0.0.1 8545
curl 'http://127.0.0.1:38545/rpc?cmd=getinfo'
