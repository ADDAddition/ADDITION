1. What this is

ADDITION is a C++ research prototype for a post-quantum Layer 1 experiment. The runnable default is additiond --network testnet (addition-testnet / ADDITION_TESTNET_V1). There is no live public mainnet in this repository.

Source: https://github.com/ADDAddition/ADDITION

2. Problem statement (research framing)

Shor’s algorithm threatens elliptic-curve signatures used by many existing chains. This project experiments with lattice-based signatures at the node, not as a claim that the network is production-ready or “quantum-safe forever.”

3. Research goals (design targets)

  1. Quantum — ML-DSA-87 (FIPS 204) via liboqs. getinfo reports pq_mode=strict when the node answers. Build fails if liboqs is missing.
  2. Privacy — SHA3-512 commitment + nullifier opening (privacy_mint_open / privacy_spend_open). This is a hash relation, not a native ZK circuit. Not Groth16, not ZK-Shield.
  3. Speed — local testnet RPC. Publish only real getinfo fields from a running process.
  4. Cost of transaction — spec min_fee=1. This site does not invent USD fees or a gas market.
  5. Compatibility — in-process bridge_* commands and web/evm/evm_rpc_bridge.py. Bootstrap / not a full EVM, not live Uniswap, not connected to every chain today.

Hashing in the daemon is SHA3-512 (OpenSSL). crypto_selftest is whatever the node returns; if RPC is down this page does not invent a pass.

4. Consensus experiment: Proof of Measurable Work

The miner/chain use a memory-hard scratch path (about 1 MiB in chain.cpp) plus SHA3-512. getinfo can report last_mine_ms, last_mined_txs, and last_tps from that process. Those fields are not a public hashrate index.

5. Ledger and contracts (what the code does)

  • UTXO-style transactions with PQ signatures and a minimum fee. Local wallets use createwallet (ML-DSA-87) and wallet_send / tx_build+sendtx_signed. Bitcoin-like user model, not BIP compatibility.
  • In-process key-value contracts: contract_deploy, contract_call set|add|get.
  • Token / NFT / swap engines in-process. A swap quote without a pool returns error: pool not found.
  • EVM helper is a bootstrap JSON-RPC map. Not a full EVM. eth_sendRawTransaction is disabled.
