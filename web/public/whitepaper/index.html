1. What this is

ADDITION is a C++ research prototype for a post-quantum Layer 1 experiment. The runnable default is additiond --network testnet (addition-testnet / ADDITION_TESTNET_V1). There is no live public mainnet in this repository.

Source: https://github.com/ADDAddition/ADDITION

2. Problem statement (research framing)

Shor’s algorithm threatens elliptic-curve signatures used by many existing chains. This project experiments with lattice-based signatures at the node, not as a claim that the network is production-ready or “quantum-safe forever.”

3. Cryptography actually in the daemon

  • Signatures: ML-DSA-87 via liboqs (createwallet reports algo=ml-dsa-87). Build fails if liboqs is missing.
  • Hashing: SHA3-512 (OpenSSL) for addresses, transactions, and block headers.
  • Self-test: crypto_selftest on a running node. If RPC is down, this site does not invent a pass.

4. Consensus experiment: Proof of Measurable Work

The miner/chain use a memory-hard scratch path (about 1 MiB in chain.cpp) plus SHA3-512. getinfo can report last_mine_ms, last_mined_txs, and last_tps from that process. Those fields are not a public hashrate index and must not be shown as “124.8 KH/s” or similar marketing.

5. Ledger and contracts (what the code does)

  • UTXO-style transactions with PQ signatures and a minimum fee.
  • In-process key-value contracts: contract_deploy, contract_call set|add|get.
  • Token / NFT / swap engines in-process. A swap quote without a pool returns error: pool not found.
  • EVM helper is a bootstrap JSON-RPC map. Not a full EVM. eth_sendRawTransaction is disabled.
