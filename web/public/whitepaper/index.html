From docs/WHITE_PAPER.md, config.hpp, genesis.json. Default: additiond --network testnet.

1. What this is

C++ node. Post-quantum signatures (ML-DSA-87) and SHA3-512. Network name addition-testnet / ADDITION_TESTNET_V1.

Source: https://github.com/ADDAddition/ADDITION

2. Why lattice signatures

Shor’s algorithm breaks elliptic-curve signatures. This node uses ML-DSA-87 via liboqs. Build fails if liboqs is missing.

3. What the node does

  1. Quantum — ML-DSA-87 (FIPS 204). getinfo prints pq_mode when the process answers.
  2. Privacy — SHA3-512 commitment + nullifier opening (privacy_mint_open / privacy_spend_open). Hash relation. Not Groth16.
  3. RPC — public read on :38545 (getinfo, getblock, …). Write RPC on 127.0.0.1:8545.
  4. Fees — spec min_fee=1.
  5. Bridges — in-process bridge_* and web/evm/evm_rpc_bridge.py on localhost. eth_sendRawTransaction disabled.

Hashing: SHA3-512 (OpenSSL). crypto_selftest is whatever the node returns.

4. Proof of Measurable Work

Miner/chain: memory-hard scratch (~1 MiB in chain.cpp) plus SHA3-512. Testnet PoW is sha3_512. getinfo may print last_mine_ms, last_mined_txs, last_tps from that process.

5. Ledger

  • UTXO txs, PQ signatures, min fee. createwallet (ML-DSA-87), wallet_send / tx_build+sendtx_signed.
  • In-process KV: contract_deploy, contract_call set|add|get.
  • Token / NFT / swap engines in-process. Empty pool → error: pool not found.
