● Testnet

Run a node

Build additiond from source and join the research testnet. Your node holds your keys; its write RPC stays on 127.0.0.1.

Pre-mainnet. ADDITION mainnet has not launched. The code is public and tested on local and research testnets; there is no live mainnet, no listed coin and no sale.

Steps

  1. Install the dependencies

    A C++20 compiler, CMake, Ninja, OpenSSL and liboqs 0.12 (for ML-DSA-87). The shielded pool also needs a Rust toolchain.

    sudo apt install build-essential cmake ninja-build libssl-dev tor
# liboqs 0.12.0
git clone --depth 1 -b 0.12.0 https://github.com/open-quantum-safe/liboqs
cmake -S liboqs -B liboqs/build -G Ninja -DCMAKE_INSTALL_PREFIX=$HOME/oqs -DOQS_BUILD_ONLY_LIB=ON
ninja -C liboqs/build install

  2. Build ADDITION

    git clone https://github.com/ADDAddition/ADDITION
cd ADDITION
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=$HOME/oqs
ninja -C build additiond
ctest --test-dir build    # optional: run the test suite

  3. Start Tor and the node

    Peers connect through Tor v3 onion services. Use the testnet bootstrap peers listed in the repository runbook.

    sudo systemctl start tor
./build/additiond --network testnet --onion-only --tor-proxy 127.0.0.1:9050 \
  --bootstrap <peer>.onion:PORT

  4. Create a wallet and mine

    Commands go to your node's local RPC (one line in, one line out).

    printf 'createwallet alice\n' | nc 127.0.0.1 8545
printf 'getinfo\n'            | nc 127.0.0.1 8545

Mainnet

The --mainnet profile exists in the code but there is no live mainnet. Its seeds will be Tor onion addresses loaded from seeds-mainnet.txt; that list is empty until real seed nodes are published. See the runbook.

Ports

P2P 28545 (testnet) / 28546 (mainnet). Write RPC on 127.0.0.1 only (8545 / 8546), never expose it. Optional read-only public RPC 38545 / 38546.

Safety

Never share your data/wallets/*.wal files, node identity or .env. Nobody from the project will ask for them.
